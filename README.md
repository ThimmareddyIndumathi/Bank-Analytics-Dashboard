Bank Analytics Dashboard 🏦📊
A data-driven Bank Analytics Dashboard built using Excel to analyze key financial metrics, customer transactions, and loan performance.

📌 Project Overview
This Excel-based dashboard provides an interactive view of key banking metrics, including:

📊 Revenue & Expenses Analysis
🔍 Customer Transactions Overview
💰 Loan & Credit Risk Evaluation
📈 Trend Analysis & Forecasting
🛠 Tools Used
Tool	Purpose
Excel	Data cleaning & dashboard creation
Pivot Tables & Charts	Data visualization
Power Query	Data transformation
Conditional Formatting	Data insights highlighting
📂 Dataset
Filename: Finance_dataset1.csv, finance_dataset2.xlsx
Columns: Customer ID, Account Type, Loan Status, Transaction Amount, Interest Rate, Date, etc.
Source: Bank transaction data
📥 How to Use the Dashboard
Download the Excel file from this repository.
Open it in Microsoft Excel (2016 or later).
Navigate through the dashboard:
Use slicers to filter data by date, region, or transaction type.
Analyze key financial metrics in pivot tables & charts.
